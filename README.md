# tModLoader

### Terraria's official modding platform

tModLoader is the official Terraria mod platform, co-developed with Re-Logic. It provides a mod browser, automatic mod loading, and a comprehensive API that has enabled thousands of community mods for Terraria.

<br>

---

## Features

| | |
|:---|:---|
| **Official Platform** | Developed with Re-Logic's blessing and sold on Steam alongside Terraria |
| **Mod Browser** | Browse, download, and update thousands of mods from inside the game |
| **Multiplayer Sync** | Mods automatically sync between host and joining players in multiplayer |
| **Rich API** | Comprehensive modding API covering almost every aspect of the game |
